# 20 题配对短测

2026-11-17，ABCD 与 ABCDG 各回答同一组 20 道独立题，共 40 次任务。结果：两组内容与严格 JSON 正确率均为 20/20。

| 指标 | ABCD | ABCDG |
|---|---:|---:|
| 累计输入 token，含裁判 | 186,759 | 167,580 |
| 累计输出 token | 3,401 | 3,421 |
| 缓存感知估算费用 / CNY | 0.19450852 | 0.12997792 |
| 同时段全部未命中重算 / CNY | 0.400726 | 0.362528 |
| 总墙钟时间 / 秒 | 159.075 | 160.871 |
| 额外回读 | 1 | 1 |
| 独立裁判请求 | 20 | 20 |

两组全部请求合计约 0.32448644 元；无未知 usage 或自动付费重试。费用依据用量和公开价格估算，没有查询账户账单。

## 方法

- 每题每组使用独立新会话和裁判缓存；奇数题先 ABCD，偶数题先 ABCDG，串行执行、共用预算账本。
- 主模型与独立裁判均为 `deepseek-flash`；主模型关闭思考、输出上限 768、temperature=0。
- 工具为原生 `read` / `pwsh`，保留 Windows 工具隔离；模型只能读本题材料及归档，不能读预存答案。
- 正式请求前冻结题目、答案、实现和材料；结束后检查指纹一致。
- 固定答案逐字段评分，不用模型主观判分。严格评分要求直接可解析 JSON 且类型和值一致；内容评分额外允许去掉 Markdown 围栏和将数值字符串无损转为要求的数字。本轮两种评分相同，38 个字段全部正确。
- 12 题覆盖 G 的重复文本条件，实际压缩 12 次、净减少 131,028 字符、模板计算合计约 42.78 ms；所有输出在实际模型投影中可见，逐行重建及归档检查通过。另 8 题正常跳过 G。
- 每组 20 次裁判请求实际用于技能筛选；原生测试日志在本轮由规则压缩，未触发额外日志裁判。

## 范围

18 道合成材料题和 2 道已有的真实 Django 日志 / 源码题。合成题包含否定、边界、Unicode、编号、状态、计算与不可信指令。12 题特意包含 G 可处理的重复结构，8 题控制短文本、非重复文本、其他扩展名、原样请求与原生测试日志。

没有重跑完整 Django、SWE-bench、原版 B0 或无 Sieve 的 DSH。小样本与机制分层不能代表一般任务分布，也不能保证完整代码任务或长会话不退化。

## 保存的证据

- `results.json`：每题答案、评分、用量、费用、耗时、回读和 G 实际应用。
- `reconstruction-verification.json`：每份 G 输出的还原 / 完整归档检查。
- `formal-freeze.json`：本机原始实验冻结时的哈希。
- `implementation-fingerprint.json`：原实验的 ABCD 与 ABCDG 编译产物指纹。
- `fixture-hashes.json`：原始材料哈希。

仓库只发布结果与指纹，没有发布原始会话、API 流水、机器状态或完整实验运行环境。这些哈希用于溯源，不表示克隆本仓库即可重新运行同一付费实验。免费代码测试可按根目录说明运行；完整付费复测需要另建材料、会话与账本。
